## 📖 Overview
The **WorkItem Redirector** is a simple tool designed for quickly navigating to specific work items within your development environment. Enter a WorkItem ID, click a button, and get redirected instantly.

## 🚀 Live Demo
Try it out [here](https://vr-malaadin.github.io/workitem-redirector/).

## 🛠️ How It Works
1. Open the [WorkItem Redirector](https://vr-malaadin.github.io/workitem-redirector/) in your browser.
2. Enter a WorkItem ID in the provided input field.
3. Click "Open WorkItem" or press `Enter` to be redirected.

## 🎨 Features
- **Instant Redirection**: Quickly access work items with a single input.
- **Embedded Mode**: Option to open work items within the page (local use only).
- **Mobile-Friendly**: Fully responsive design.
- **Error Handling**: Alerts for invalid or empty inputs.
- **Persistent Input Focus**: Enhances workflow efficiency.

## 🔧 Customization
### URL Configuration
Adjust the work item URL to fit your environment by modifying the `redirect()` function in the JavaScript section.

### UI Styling
Customize the layout by modifying the CSS in the `<style>` section.

## 📌 Additional Notes
- **Embedded Mode Warning**: This feature works only when running locally.
- **Security**: Ensure you are authorized to access the work items in your environment.
